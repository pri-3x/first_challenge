Spot Lender

The lender holds 50 WETH. It lets an account borrow up to half the USD value of posted collateral. That value comes from the spot pool's current reserves. Debt is recorded, so the same collateral cannot be borrowed twice.

Accounts 1 through 5 each start with 1 WETH and 10,000 USD. At the opening price, 2,000 USD per WETH, those funds can borrow 2.5 WETH. FlashLender will lend its WETH to a contract that pays the same amount back before the call returns.

Empty the lender's WETH balance. solved() becomes true only after the lender has an outstanding borrow and holds no WETH.
